# 급속 충전기 단말기 오류 코드 안내 (학습용 예제 문서)

이 문서는 챗봇 시험용으로 만든 가상의 오류 코드 표입니다. 실제 제품의 코드와는 관계가 없습니다.

## 통신 오류 (E-1x)

E-11 서버 통신 끊김: 단말기가 관제 서버(OCPP)와 60초 이상 연결되지 않았습니다. LTE 모뎀 전원과 안테나를 확인하고, 단말기를 재부팅합니다.

E-12 인증 응답 지연: 회원 카드 인증 응답이 10초 안에 오지 않았습니다. 서버 상태를 확인하고 다시 태그하도록 안내합니다.

## 충전 오류 (E-2x)

E-21 절연 저항 이상: 충전 시작 전 절연 검사에서 저항값이 기준(100kΩ) 미만으로 측정되었습니다. 충전 커넥터와 케이블의 손상, 습기를 확인합니다. 같은 차량에서 반복되면 차량 쪽 점검을 권합니다.

E-22 커넥터 온도 높음: 커넥터 온도 센서가 90℃ 이상을 감지해 출력을 멈췄습니다. 10분 이상 식힌 뒤 다시 시도하고, 반복되면 커넥터 핀 마모를 점검합니다.

E-23 비상 정지 버튼 눌림: 비상 정지 버튼을 시계 방향으로 돌려 해제한 뒤 화면의 "복귀"를 누릅니다.

## 결제 오류 (E-3x)

E-31 카드 리더기 응답 없음: 결제 단말(카드 리더기)과의 RS-232 통신이 끊겼습니다. 케이블 연결을 확인하고 단말기를 재부팅합니다.

E-32 결제 승인 거절: 카드사에서 승인을 거절했습니다. 다른 카드로 결제하도록 안내합니다.

## 충전 시작 절차

1. 화면에서 "충전 시작"을 누릅니다.
2. 회원 카드를 태그하거나 신용카드로 결제합니다.
3. 커넥터를 차량에 연결하면 절연 검사 후 충전이 시작됩니다.
4. 충전을 끝낼 때는 화면의 "충전 종료"를 누르고 커넥터를 거치대에 돌려놓습니다.
