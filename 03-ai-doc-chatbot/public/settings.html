외부 AI 연결 (OpenAI · Claude)
API 키 넣는 방법

키는 보안을 위해 화면에서 입력하지 않고 Worker 비밀 값으로 넣습니다. 화면에는 들어 있는지만 보입니다.

로컬(npm run dev): 프로젝트 폴더의 .dev.vars 파일에 한 줄씩 적고 다시 실행

OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...

배포본: PowerShell 에서 아래 명령을 실행하고 키를 붙여 넣기 (다시 배포할 필요 없음)

npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put ANTHROPIC_API_KEY

AI Gateway 에 인증을 켰다면 CF_AIG_TOKEN 도 같은 방법으로 넣으세요. 키를 Cloudflare 대시보드의 AI Gateway "Provider Keys(BYOK)" 에 저장해 두는 방법도 있습니다.

⚠️ 외부 AI 를 고르면 질문과 검색된 문서 조각이 OpenAI·Anthropic 서버로 보내지고 사용한 만큼 그 회사에 요금이 나갑니다. 검색(임베딩)과 OCR 은 계속 Workers AI 를 씁니다.
